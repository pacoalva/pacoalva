# pacoalva

Este repositorio contiene un ejemplo sencillo de sistema de tarjetas de estudio.

## Cómo usar

1. Asegúrate de tener **Python 3.11** o superior instalado.
2. Ejecuta el archivo `flashcards/flashcards.py`:

```bash
python3 flashcards/flashcards.py
```

Se cargará el conjunto de tarjetas ubicado en `flashcards/data/flashcards.json` y se iniciará un pequeño cuestionario interactivo por consola.
